# skydipole: Monopole-Aware Dipole Estimator

This repository contains the source code, dataset, and scripts to reproduce the results presented in the Computer Physics Communications (CPC) manuscript: 
**"skydipole: a monopole-aware dipole estimator for binary-labelled sky catalogues, with an application to galaxy spin handedness in Galaxy Zoo 1"**.

## Requirements
The package is written in Python 3.10+ and requires the following standard scientific libraries:
- NumPy
- SciPy
- pandas
- Matplotlib

You can install the required dependencies using:
```bash
pip install -r requirements.txt
